2D Spatial Canvas

Two p5.js sketches. The static sketch renders a lakeside scene (forest backdrop, water, randomly placed islands, a small swan, and grass). The interactive sketch draws colored circles at the mouse position; color and size map to cursor X/Y, and clicking clears the canvas.

3D Spatial Canvas

Two Three.js scenes. The first extrudes a mathematical heart curve into 3D and rotates a trio of hearts under basic lighting. The second adds OrbitControls, hemisphere/directional lights, a shadow-receiving floor, a reflective sphere, and a spinning torus-knot for interactive navigation.

1. Rotating Box
2. Interactive 3D

Temporal Structure

D3.js visualizations over local CSVs. The synthetic series renders a line chart with focus tooltip, a value histogram, and extrema markers with a mean line (dataset: ./temporal_structure/synthetic-data.csv from the example repo). The event dataset builds a timeline colored by category and a duration histogram (dataset: ./temporal_structure/events.csv from the example repo).

Relational Structure

A force-directed network built with D3. Nodes (size/color by attributes) and links (thickness by strength) are draggable and zoomable, with arrowheads for directed edges and tooltips showing per-node details. Datasets: ./relational_structure/nodes.csv and ./relational_structure/edges.csv from the example repo.

Spatial Structure

A Mapbox GL visualization of Chicago museums. Points are styled circles with labels; clicking a point opens a popup with name/description, and the map exposes standard navigation controls. Dataset: ./spatial_structure/museum_chicago.geojson with mind drawing with geojson.io.

Engagement Poll

A minimal Firebase Realtime Database poll. Two buttons increment yes/no counters via a transactional update; a live listener updates totals and briefly animates numbers when values change.

GPT Chat Bot

A lightweight chat UI that loads an API key from a local text file and submits prompts to the OpenAI Chat Completions API. Messages append to a chat pane; Enter or the Send button triggers a request, with a placeholder typing indicator while waiting.
